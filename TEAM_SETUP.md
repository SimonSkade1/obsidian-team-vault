# Team setup

One folder shared by several people, no server software: each member's Obsidian works on a local copy and [Syncthing](https://syncthing.net) keeps the copies identical. One always-on machine (a small VPS, or a desktop that stays on) is the **hub**: the only device that shares the folder — every member connects to it and to nobody else (hub-and-spoke: one authoritative copy, one accept per new member, no laptop that was offline for a month pushing its stale deletions onto everyone). The hub also runs the nightly jobs: a git snapshot of the vault, the daily/weekly/monthly summaries in `periodic-auto-summaries/`, and every second day a cleanup that puts misplaced files where the conventions say. Everything per person — `_local/me.md`, `.obsidian/`, the personal `CLAUDE.md`, private notes — stays off the network through `.stignore-shared`.

1. **Hub** (headless, no Obsidian needed): clone the repo, delete `.git`, then follow [`other-files/VPS_SETUP_INFO.md`](other-files/VPS_SETUP_INFO.md) — the Syncthing folder and its ignore line, a fresh git repository, `_local/me.md`, the systemd timer (or launchd / Task Scheduler) for `run-daily-review.sh`, a logged-in Claude Code, the token-free checks.
2. **Members** follow [`INSTALL_AND_SETUP.md`](INSTALL_AND_SETUP.md) — Syncthing, then they send the hub admin their device ID (`other-files/add-member.sh <DEVICE-ID> <name>` on the hub adds them), accept the share, install Obsidian and Claudian, and say `complete the setup`. They never clone anything: the files arrive through Syncthing.
3. **Fill in your own names.** The docs and config are the original team's, with placeholders where the value is yours: `<HUB-NAME>`, `<HUB-DEVICE-ID>` / `<HUB-DEVICE-ID-PREFIX>` and `<HOST-IP>` in `INSTALL_AND_SETUP.md` and `other-files/VPS_SETUP_INFO.md` (known once the hub's Syncthing runs); `<vault-owner>` in `.claude/CLAUDE_shared.md` (who receives Claude's bug reports); `OWNER = "simon"` in `other-files/check-unassigned.py` (who gets the inbox task about items without an owner). The vault folder is `obsidian-team-vault`, the Syncthing folder id `team-vault`, its label `Team vault`, the systemd units `team-vault-daily-review.*` — rename them only if you want to (they recur in `INSTALL_AND_SETUP.md`, `other-files/systemd/`, `add-member.sh`).
4. **The conventions everyone shares** are in `README.md` (for people) and `.claude/CLAUDE_shared.md` (for Claude): exactly one owner per item, `next_action_by` to hand something over, everyone sees everything, no secrets in the vault. Personal instructions go in each member's unsynced `.claude/CLAUDE.md`; changing the shared files is a team decision.
